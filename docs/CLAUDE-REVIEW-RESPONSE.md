## 兼容与独立复审修正

- 旧版已封存概率按原始身份及摘要读取。普通 B1 入口遇到内置程序版本变化时为新比赛登记带独立指纹的配方；之前封存的比赛继续使用当时的版本。具名研究配方无法用新代码冒名执行。实测旧技术预测在升级前后返回完全相同的正文和摘要。
- 首次发现赛事已经错过决策窗时，调度按原时点记漏采。Gamma 当时已经归档而本机晚运行，与来源首次出现过晚分别归因。赛程移出七天、随后恢复原时刻时，仍未到期的时隙可重新排程。
- 在尚无影子持仓时，查询返回“尚未开始”、空清单和空收益。资金仅在首次实际启用该研究账户时建立。

## 复测顺序

1. 从干净检出安装研究约束。先运行 `ruff check src tests scripts` 和 `python -m unittest discover -s tests -v`。浏览器测试使用 Playwright 和 `PM861_TEST_CHROMIUM` 指向的 Chromium。
2. 在独立运行目录按 README 抓取 17 季固定原件，分别运行严格及 24 小时延迟的五季回测；加 `--details` 可独立重算逐场分数。外审评分脚本核对 3,800 个时点记录，最大误差为 1.42×10⁻¹⁴。另复跑小样本区间模拟及 16 组历史超参数，对已选模型的说明据此修订。
3. 用 `experiment football-study` 重跑两个候选。用本地市场夹具的 `decision_window_benchmark.py`、`capture_schedule_check.py` 对照时间窗和性能。历史行情回补可反复运行；需要实时订单簿和双方名单的验收须留到真实比赛窗口。
4. 使用 `season status`、`trial readiness` 和 `shadow report` 交叉查看采集覆盖、正式门槛与影子样本。审核合成时间窗与真实公网收件时分别计数。无可验证的正式成交时，ROI、CLV 保持空值。[本版独立审核](./INDEPENDENT-REVIEW-0.2.0.md)
