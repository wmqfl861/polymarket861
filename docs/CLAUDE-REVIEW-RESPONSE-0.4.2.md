## 独立复查后追加的修复

- 两份原件都提供完整姓名时，显示名或同姓无法覆盖全名冲突。其他球队的旧格式目录也要核验，避免跨队重复编号取得豁免。
- 两个来源先同意比分、后来同时出现比分与开球时间分歧时，旧终场不能继续支撑出场目录。按过去的截止查询仍能还原当时的判断。
- 固定封存写入前重开两源原件；在原件与派生索引不一致、后到改时或开球证据尚待解释时，保持阻塞。已写但尚未提交时原件发生变化，一并回滚预测及报告。盘口研究也核对原始交易所历史，早前已开始的事件不能用后来恢复的赛前标记重新纳入。
- 斜率区间只使用有识别能力的轮次。给两个有效轮次再加 36 个零变动轮次，两次计算的斜率都为 1，自由度都为 1，区间同为约 `[−14.28, 16.28]`。零变动仍进入覆盖分母。
- 跨概率版本重放现在识别比赛去重、球队标准化和有效比分范围的代码变化。归档轮询的单次收件哈希或成员列表损坏时，该时点的研究资格被撤下，相邻完好的原件仍可使用。
