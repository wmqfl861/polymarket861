## 赛前输入及赛后纠错

| 独立复验 | 冻结版观测 |
|---|---|
| 背靠背、实收截止与一致性 | 45 份已结束比赛加一份已知但未开打的前一晚赛程，T−24h 实际封存与同一截止的公开预览均给出 N2 主胜概率 0.4252873563，训练摘要相同。缺少赛地标志时停用主场优势，并标出原因。 |

| 写入跨越截止 | 以第二个 SQLite 连接实际持有读锁，拖延预测事务直至超过固定截止至少 1 秒。窗口记漏封，提交数为 0。再用读锁拖延比分入库，释放前时点在当时及事后回放均取到 0 份新版本。 |
| 交叉来源冲突 | BDL 仍称待赛而交易所已记第一节时，实际封存和交互预览均拒绝。两个不同事件共用同一交易所游戏 ID 时，冲突后旧、新双方均退出资格，先前时点仍可重建，后续正式封存为 0。 |
| 延期合约的有效期限 | 独立重读已存 Gamma 事件 1377575。原定开赛为 11 月 28 日 00:00 UTC，条款截止为 11 月 30 日 04:59 UTC。原有六个合约覆盖四个玩法，改期到截止前两小时仍有六个合格。改到截止后一秒，竞技盘口对照为零，六份原生条件仍可追踪最终兑付。 |
| 分布及可重复评分 | 对 N0/N1/N2 分别从整数联合比分重新合成主客胜、两队分和总分，并用显式双重求和重算 CRPS 及胜方 Brier。无平局，三层均吻合。终场确认、改判、撤回、重新确认依次产生五个评分状态。更正及撤回后旧周报仍可按版本读回，封存内容与摘要不变。 |
| 盘口和不确定度 | 同窗同臂的报告有竞技评分、实际配对数及与盘口 Brier 差。至少有四个配对比赛日才显示该期按美东比赛日整组重抽的探索性区间。新到的决策报价不能回填已封存盘口。 |
