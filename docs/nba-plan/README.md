## 用户会得到什么

打开一场比赛可以看到双方、比赛阶段、球馆、当地时间及自己的时区、最新赛程版本、预测封存时点、最可能分差及总分区间。核心输出为胜负、全场大小分、主队大小分、客队大小分，同一个联合得分分布可查询不同分数线。列出纳入的球员、出场状态、预计分钟及信息来源，也能查看球员出战/限时/缺席三种情景各自如何改变球队得分和胜率。消息发生变更时保留上一版和原因。每条已挂牌合约旁列明结算分数范围、双方令牌、实收时间、最佳卖价、指定金额能买的数量及费用证据。缺少队别、盘口规则、可买深度或实际赛前证据时，仍可查看有依据的模型结果。

以主力后卫临场休战为例，T−60 分钟只封存当时收到的状态，给出可证实的出场权重或分情景结果。若 T−28 分钟收到球队确认休战的合格来源，AI 将状态变更绑定到具体比赛和球员，去重后重新分配控球、替补分钟和使用率，显示对两队得分分布的影响。可在 T−15 分钟研究预测中看到这次调整。当天结果出来后，同场同窗比较有无这条信息的两个版本。最后以 Polymarket 实际兑付另行核对模拟资金。这一场、这一条新闻、多个盘口各有自己的分母。
