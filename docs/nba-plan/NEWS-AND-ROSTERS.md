## 从一条消息到球队预测

1. **来源与时间。** 保存上游署名、来源 ID、原始地址或允许保留的指纹、索引时间、发布与更正时间、首次实收和解析/准入时间。所有时间参与同一个预测截止校验。仅允许规范事实时按许可保留，要求独立回读原件的研究应列出不可复验的分母。文章中的文字为不可信输入，不能调用工具、更改授权或签发比赛结论。
2. **AI 提取。** 从获准材料抽取球员、球队、赛事、比赛、发言人、消息层级、状态、否定词、条件、有效期及可核验的证据片段或定位。记录模型、提示模板、输出版本。区分恢复轻量训练、全量训练、赛前热身、允许出战、限制分钟、预计或确认首发。官方确认一名球员处于“出战存疑”，只能确认这一状态。原话不足或身份不唯一进入待审。
3. **绑定身份。** 用稳定球员 ID 加球队隶属的生效区间处理重名、后缀、变音符、交易生效、十天合同及双向球员。按当时的赛事、对手与阵容绑定，跨队旧报道不能打到新球队。比分、首发或停赛的公告更正连接原记录，保持原封存可复查。
4. **处理冲突。** 发言源头、通讯社和转引链相同的内容合成一个事件簇。新官方声明、赛前退出、限制调整或撤回均以实际收件后生效。同等级可靠证据矛盾则输出未知，保留双方。球员从下一版清单消失、下载失败、过期、尚未提交不自动转成可用。一位球员列为替补也不能证明他必然上场。
5. **转换为轮换与强度。** 给有资料的球员建缺阵、受限、正常出战等互斥情景，分配合理的轮换分钟及替代人选，再计算回合数、进攻/防守强度和比分分布。球队近期表现若已反映长期缺阵，只计算新增或改变的影响。教练更替、已确认轮换调整、连客/休息和有来源的旅程中断记生效场次。私人传言、无依据的士气或未公开诊断不赋数值。可用性、是否首发、是否登场和实际分钟分别作为标签。
6. **展现与封存。** 看板给出源头、时间、具体球员、状态、角色、分钟和概率差，分别标识传闻与已确认。T−24h、T−60m、可选临场影子观察独立评分。无新实质变化时只追加证据，新消息不能改写已经封存的预测或该时点的模拟入场价。

## 验收和改进

| 交付 | 具体验收 |
| --- | --- |
| 解析与时间边界 | 独立验收样例应包含两天比赛同一 PDF、跨页空队名、同 URL 修订、报告缺页、同名、迟到、撤回、热身退出、今晚/明晚歧义、改期和夏令时。用赛后阵容回填、跨场证据、未来分钟等专门反例验证拒绝。 |
| 逐队覆盖、时效与提取正确性 | 分母为各队在各预定比赛及时间窗的应收件。报来源覆盖率、链接率、获权有效事实率、收件延迟与入模延迟中位数/P90、无法绑定和争议比例，拆分背靠背与普通比赛。独立双人盲标事件簇，确认缺阵与先发分别评精确率/召回及区间，设不命中消息的人工抽样。可提请采用足球已验的“84 个独立事件、至多错 3 个且 Wilson 双侧 95% 下界至少 0.90”作为确认缺阵精确率门槛；NBA 另做登记与采样，不能继承足球认证。[既有准入办法](../five-leagues-0.5/NEWS-ADMISSION.md) |
| 同窗配对和根治错误 | 对相同比赛、截止和盘口比较球队基线、仅结构伤停、加赛前明确阵容、再加获准记者消息。单列各层覆盖和全赛程结果，胜负、全场大小、主客单队大小分开考察校准及预测误差。未获权或始终缺资料的队照实列在分母。发生错误时追踪至字段、来源和解析版本，列受影响预测、隔离有误的来源，保留原评分，另发更正及重放结果。根因修复后以同一反例验收，由人工核准来源/模型晋级，按比赛日及赛周报告。 |
