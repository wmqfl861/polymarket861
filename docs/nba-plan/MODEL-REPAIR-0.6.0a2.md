# NBA 球队模型复核与部署预热

本次对应 Claude 审核 Y1-2、Y1-4、Y2-3、Y3-3。新配方为 `nba-final-paired-residual-v2`。N0 仍使用联盟比分对，N1 加入球队攻防，N2 在 N1 上为背靠背休息差固定调整 **1.5 分**。球队更新率 0.065、跨季保留 0.60、残差库上限 1,200 场均沿用原值。三层模型共用赛地处理及含加时的终场定义。[源码](../../src/polymarket861/nba/model.py)

## 赛地如何影响预测

普通常规赛的来源给出挂牌主客队、未提供球场性质时，训练和推断均按挂牌主队处理，记录 `assumed_listed_home`。来源明确给出的中立场记录为 `confirmed_neutral`。当日期与双方球队和已核实公告相符时，用 `documented_neutral` 记录公告地址，即使来源把挂牌主队标成非中立也会采用这个公告。中立场采用无主场优势的分布。训练摘要同时给出原始赛地缺失数、按挂牌主场推定数和公告确认的中立数。

名单收录了 2022/23 至 2026/27 核对过的巴黎、伦敦、柏林、曼彻斯特及墨西哥城比赛，以及 2023、2024、2025 年拉斯维加斯杯赛半决赛。以一场为单位匹配日期和双方队名，名单可能遗漏临时迁场等情况。只有在公告发布日结束后（美东时间）才允许使用这条资料。比赛改期或对手变更要重新核对。当前名单及每组公告链接可逐项检查。[赛地资料表](../../src/polymarket861/nba/venue.py) · [2026/27 起杯赛半决赛改在球队市场举行](https://pr.nba.com/nba-cup-semifinal-host-sites-coachs-challenge-rules)

## 用部署机免费比分独立复核现代五季

```bash
pm861 --data-dir /srv/pm861/nba nba model modern-study --sync > nba-modern-bdl.json
```

命令固定以 2020/21 预热，合并评估 2021/22 至 2025/26，复用前述赛季完整性检查，包括逐队场数和所有已过日期的来源扫描。全部满足才运行两个滞后口径、各 10,000 次区块重复，写出分季和合并 Brier、全场和单队 CRPS、N2−N1 区间及分差校准量。未完整时以非零状态退出，JSON 列明缺失赛季和本次请求结果。在部署方有免费 BDL 密钥时可独立复核。提交环境实跑这条命令得到 `missing_key`，本次 BDL 实收为零。[BDL 环境实测](../../reports/nba-phase1/v2-bdl-study-status.json)

历史赛果在今天回填能支持技术回放。新闻、球员状态的增益和与同一时刻 Polymarket 报价的差异，需要真实赛前封存后评测。历史比分回填不会补写曾经错过的报价、新闻或预测。

## 独立审核后的回归

1. **无开球时刻的未来终场。** 审核用一次真实采集入口的模拟 HTTP 回包，在美东 11 月 27 日上午提前报告了 11 月 28 日比赛的终场，且没有精确开球时刻。修复后该扫描给出 `source_quality`，比分待核。11 月 29 日比赛的预测训练场数保持 35，N2 主胜概率保持 0.8571428571，输入摘要完全一致。旧库存和原始缓存即使在比赛日之后重读，仍按最初实收时间核验。这条规则也作用于球队休息天数和预热统计。已过去的比赛在比赛日或更晚合法收到终场时，可以按日级数据训练。[原情景复跑](../../reports/nba-phase1/v2-premature-final-probe.json)
2. **两套队名缩写的中立场。** 名单匹配使用与市场联接相同的队名标准化。验证了 2025 年 ORL–NY、OKC–SA 和 2023 年 LAL–NO 三场，交换挂牌双方和缺失球场标志时均能找到对应公告。[回归测试](../../tests/test_nba_model.py)
