# NBA 历史回测、前向测评与纠错计划

**提审稿，2026-11-27。** 本章给出开发后的验收设计、拟登记阈值与运行口径。本次尚未训练 NBA 模型、打开模型对照留出集、登记前向试验或运行 NBA 资金回放。足球现有赛季得分、新闻协议、费用批准和账户余额各自独立。[足球研究口径](../five-leagues-0.5/MODEL-AND-VALIDATION.md) · [现有模拟账户约束](../five-leagues-0.5/PAPER-RISK.md)

## 比较单位与结果版本

一个预测单位取稳定的 NBA 比赛 ID、赛程版本、预登记时点、候选模型版本和比分口径。客队两周内两次拜访同一主队也要区分。按 NBA 赛历的比赛日归档，保存美国东部时区、场馆当地时间和对应 UTC 时刻。时窗计算使用 UTC 和截止前可见的开赛时间。T−24h 为早期预测，T−60m 为主研究与单次纸面决策时点，T−15m 单独评估临场首发；窗口长度、调度余量和入场时延须在采第一场计分样本前冻结。赛程更新后保留新旧计划和裁决，实际已开打、开赛状态矛盾或未能在原窗及时封存时明确记录缺件。

NBA 常规赛每队 82 场的常规赛季可用 30 × 82 / 2 = 1,230 场做整季盘点。历史异常赛季按当季实际赛制盘点。杯赛兼算常规赛的比赛只计一次，杯赛决赛单列，附加赛、季后赛、季前赛和全明星各自保留类型与资格。按官方终场、常规时段得分、各节及每个加时分别保留标签。四节后平分和完整比赛胜方是两个事件。每场以当时能核实的赛果计分，取消、暂停续赛、结果争议、赛果更正和市场无效兑付均单列。[NBA 杯赛 FAQ](https://www.nba.com/news/nba-cup-frequently-asked-questions) · [NBA 规则第 5 条](https://official.nba.com/rule-no-5-scoring-and-timing)

## 历史数据可以支持哪些结论

| 数据层 | 准入与时间 | 可发布的结果 |
| --- | --- | --- |
| 赛后归档 | 固定版本、许可、哈希、分赛季覆盖。只有赛后最终比分或最终盒分的赛程采用同一历史版本并声明局限；把各场统计滞后 24h 和 48h 重放以做敏感性分析。未记结束时间时用比赛日结束后的保守发布假设并披露，不制造实收时间。 | N0 与 N1，及有相应赛程历史的 N2 技术回测。最终盒分可给历史标签或已完成旧场的滞后特征。本场实际分钟、首发、球队赛季末场均和实际比赛节奏只可用于事后验证。 |
| 可追溯的历史修订 | 能证明来源哪个版本何时首次公开，记录版本时间、时区、原件指纹、现今取得时间和权利范围。用“按公开版本重建”标志单列。时间不明的新闻、覆写过的当前阵容、晚出的救济性补档不能重建早先时点。 | 对有时点的部分做历史敏感性分析，并列覆盖分母。官方同日多版伤病 PDF 说明选“当日最后一版”会污染早窗。档案文件内的时间无法单独证明本系统当时已取得它。[NBA 报告入口](https://www.nba.com/players/injury-report) · [11 月 26 日晚的版本](https://ak-static.cms.nba.com/referee/injury/Injury-Report_2026-11-26_07_45PM.pdf) · [次日早上的版本](https://ak-static.cms.nba.com/referee/injury/Injury-Report_2026-11-27_07_00AM.pdf) |
| 本机前向实收 | 预登记后，收件、首次持久化、当时可用的来源授权及结构化事实进入时间均满足截止。保留来源发布时间、修订关系、解析器和模型版本。受限原文只按获准留存字段和期限处理；无法形成可核验证据的来源单列缺件。 | N2、N3、N4 同窗概率对照。另需合格的成交簿和兑付证据，才可报告对应纸面交易。晚收到的正确消息可服务下一窗。 |

历史研究建议申请 2018/19–2025/26 的逐季授权输入，并先在无模型输出时写清季号、实际文件、逐队与逐时点覆盖。建议用 2018/19–2020/21 暖启动，2021/22–2024/25 按时间滚动开发与校准，2025/26 作为一次性历史留出。按季分开报告早年受疫情影响的赛历与场地。资料覆盖不足时，先缩短宣称覆盖的赛段、记录原因，再冻结新切分。已有开发人员查看过某季最终结果或模型相关分数时，记录暴露范围，已用于调参的结果归入开发集。正式增益结论再由新前向资料提供。

在每个拟预测时点重新创建训练视图，对特征标准化、球员分钟份额、主场效应、缺失值填充、线的选择、超参数和校准器均只使用更早已可得数据。同日较晚比赛能否使用早场，取决于早场终场或源更新的实际收件。实现保存训练视图摘要、输入清单、软件/依赖/随机种子、模型/来源版本和报告摘要。折内使用嵌套时间验证，先冻结选择规则、测试脚本及留出集查询权限，后一次生成签名留出报告。改模型后沿用同季作回归对照并另设前向确认窗。[滚动预测起点评估](https://otexts.com/fpp3/toolbox.html)

## 逐场打分与逐周报告

| 对象 | 每场产生的主记录 | 诊断项目 |
| --- | --- | --- |
| 全场胜方 | 主胜概率的 Brier 损失为 (p−y)²，y 取 0 或 1，同场只算一侧。并列平均对数损失，固定概率数值边界并统计被截断数。 | 胜率、可靠性图、校准截距/斜率、样本数。按主客、休息天数、球星状态与数据来源覆盖分层。 |
| 全场总分、主队分、客队分 | 各自报告整条预测分布的 CRPS，单位为分，越低越好。得分分布产生的每种玩法独立报告。 | 中位数绝对误差、50%/80%/95% 区间覆盖与宽度。实际挂牌时，再报告冻结线的大小分概率与 Brier；整数线保存低于、等于、高于三类概率，竞技评分采用三类 Brier（各类误差平方和），合约兑付另按当时条款重放。 |
| 联合比分 | 报告整数主客比分样本或联合分布；对分差、双方得分相关和加时频率做对照。 | 以能量分数作双变量诊断，记录蒙特卡洛误差。约束检查包括含加时终场平局概率为零、线越高大分概率不增、全场总分与两队分可从同一份抽样复算。 |

概率指标与分数误差保持原单位。Brier、对数损失、CRPS 和联合分布评分均可与简单基准在同一场直接对照。[Gneiting 与 Raftery 的评分规则论文](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

每比赛日生成暂报，逐周在美国东部周一至周日的比赛日范围出报告，按赛季和季后赛系列赛另汇总。最后一场已确认结束即可生成该期版本，缺赛果保留待决，补收或更正只追加新版。报告列出各时点的应预测、封存、错窗、降级、撤回、已评分、有效配对数；另列挂牌、双簿、可模拟成交、已兑付、争议、仍占款。分配覆盖分母后再分来源统计实际受影响比例。赛程未定、身份冲突和延期分别可见。无盘口同样可以评估四类竞技预测。多个消息、同场多条线、两侧代币及三时点不能使该场在一个主终点内重复加权；主场和客场单队大小各自只贡献一个分布分数。若要汇总一场多条盘口线，先按预登记权重聚合成该场一条，不能在赛后挑线。

**保留当时实际发布表现。** 每个固定窗建立应发机会清单，把赛前资格、各臂实际输出、降级、漏封及原因一并锁定。N4 无合格新闻时使用当时 N3，共同的上游故障按预登记规则同时回退。若一臂根本没发出，不做事后插补，列机会总数、两臂各自缺失和可配对比例。胜方 Brier 在 [0,1]，对缺一臂的比赛可用已知一臂和缺失臂损失上下界，给全机会差值的敏感性区间。另报结果未定数，质量不明时保留结论。赛后发现模型错源时，原时点实际输出仍对独立修正后的比赛结果计分。受污染行标出来源及影响，修源后的反事实回放另表发布。原赛后报告、标签修订和当前统计可分别重现。

## 新闻究竟有没有增益

1. **冻结比较。** N0 为历史基准、N1 为球队基础、N2 加赛历与球队状态、N3 加已准入的结构化球员状态、N4 在相同 N3 上加入已准入的可信新闻。分别保留 N1−N0、N2−N1、N3−N2、N4−N3；新闻的主检验为 T−60m 的 N4 与 N3，双方共享基础输入视图、随机数和截止。相同伤病事实由官方报告与报道同时转述时只采一次。结构化球员输入已包含的信息不得在新闻臂重复加权。无合格新闻时两臂同值并仍进入预登记总体，另报有消息及概率实际变化子集的诊断。
2. **冻结估计量。** 建议主终点为全体合格常规赛上胜方 Brier 的配对平均差 D = 损失(N4) − 损失(N3)。预先给出改善的方向。全场、主队、客队三个 CRPS 为次终点，预登记顺序，若需下单项结论，对该家庭实施 Holm 校正。T−24h、T−15m、季后赛、消息类型、明星缺阵和模型相对市场的变化另列探索结果。真实临近开赛盘口可在单独的同代币、同规则、同线配对上检验新闻是否领先后续报价，亦列唯一场数、覆盖与不确定性。
3. **冻结观察期。** 提案以登记后首个合格比赛日起、至覆盖随后一个完整 NBA 常规赛结束为固定终点。另保留同季首段覆盖及分季报告。开始前用未纳入检验的技术先导样本估计新闻覆盖、损失差波动与同日相关性，模拟在预定效应量下的把握，目标 80%，同时展示较弱信号和缺失条件。建议最小关注差为 Brier 改善 0.002，属于待审核的产品选择。样本不足则公布可检出效应与不确定结论，延长或再试须另行登记；每周公开已发布基准的实际得分、单场预测复盘、覆盖和故障，探索试验标明身份。正式 N3/N4 的配对损失差、组别汇总和检验结果在终点前对调参人员和 Codex 隔离，记录访问。样本期间固定两臂与分析，若因安全事件或可见逐场输出而提前查看正式比较，登记暴露时点和偏离，旧臂继续或有记录地终止。新候选在首次暴露和重新登记之后的新样本上独立验证。
4. **处理相关性。** 保留同场所有主客/盘口/时点和同日赛程整体。主分析以比赛等权，对连续比赛日按赛季分层做 7 日移动区块重抽样 10,000 次，同时重抽样每日损失差总和与场数，再求整体比值；3 日和 14 日作为敏感性分析。区块不得跨休赛季，保留空比赛日。报告实际周数、独立比赛数、区间和按赛季方向。检查背靠背及重复对手引出的相关性，按球队去一法与留出系列赛作稳健性诊断。建议少于 20 个有配对的自然周则标记为探索，簇或有效样本过少不出精确改善判断。该数量属于报告门槛，不能代替功效计算。[区块重抽样方法依据](https://doi.org/10.1080/01621459.1994.10476870) · [多重检验依据](https://www.ime.usp.br/~abe/lista/pdf4R8xPVzCnX.pdf)
5. **决定升级。** 建议在固定终点达到最低周数和预设功效要求、主差值 95% 区间上界小于 0 且点估计改善至少 0.002，才对胜方宣布新闻增益。大小分每类另核对校正后的结果，缺乏证据的玩法沿用已批准版本；首次上线且尚未获批时继续展示研究结果；覆盖和资料更正须通过下节完整性检查。看见结果后改变特征、来源等级、模型提词或阈值须换模型/协议版本，旧报告保留。正式启用按玩法经负责人签批。即使预测过关，有正净收益仍须单独检验。

## 价格、成交及持有到结算

在真实合约挂牌且逐项能核对比赛、代币方向、盘口线、加时范围、取消/平分/退款条件的时点固定意图。选择标的时只读决策窗已挂牌的集合，按预登记的主线选择规则或冻结的全部线出统计。用当时市场概率作比较时单列参考口径及买卖价差。Polymarket 页面展示价可能是买卖中间价或上笔成交。决策簿与后续独立执行簿分开核实，执行须发生在实际开赛前，按可买的卖方价量逐档计算均价、未成交数量和手续费。无法确认深度、时延、状态、费用或市场终态时保留具体原因；历史价曲线可用于受限的价格研究。[展示价规则](https://help.polymarket.com/en/articles/13364488-how-are-prices-calculated) · [公开订单簿](https://docs.polymarket.com/api-reference/market-data/get-order-book) · [费用说明](https://docs.polymarket.com/trading/fees)

独立 NBA 模拟账本按项目持有至交易所终局，尚未兑付时占用资金。逐场保留用于买入的现金、净到手份额、费用类型、确认兑付及其时刻。已结净损益为实际兑付额减该笔全部现金支出，按资产计费时体现在净份额，避免同额二次扣减。按期报告已结收益率（分母为已结交易的全部现金支出）、净损益、期末待结数量/成本、已结权益最大回撤、成交覆盖及价格滑移。全期未结保留在独立明细。无同线实时收盘参照时 CLV 置空；冻结同一代币最后一份合格赛前盘口的参考口径，将带方向的价格差与价格收益分开。预期优势按条款对应各状态的兑付及真实买入成本计算。结果标签和交易所取消/平分兑付可以不同，两份证据分别结算和对账。

**同时开赛与相关头寸。** 建议首发纸面策略保守地每场最多采用一个方向，四类预测全部照常评估。登记初始 NBA 专用现金、单场/比赛日上限、最大买价、最低扣费优势和固定名义金额。每个决策批次用同一份可用现金与锁定敞口，按扣费后优势、场次稳定 ID、盘口 ID 的确定顺序预留资金。用执行簿成交或释放预留；在未收到兑付前不得循环使用该笔资金。资金不足、同场多个相关机会、两个窗口针对同场、同时多场、部分成交和重启重放分别验收。多玩法同时持仓须单独建相关敞口试验。

## 数据更正与可复查的验收

| 反例或检查 | 开发完成的判据 |
| --- | --- |
| 重抓、并发、同秒比分冲突、改期 A→B→A、赛后新闻改写标题 | 同一逻辑事件幂等。原件保留，互相矛盾即暂停该条资格。新收件追加修订，早期截止的预测与训练视图仍完全可复现。 |
| 球员刚交易、预计首发后来落选、迟到伤病报告、赛中盒分、延迟兑付 | 跨队和过期消息不能生效。晚到证据对已封存概率影响为 0；技术回放和真实赛前实收分表，任何跨入前向总体的伪造回填计数必须为 0。 |
| 封存、合约规则、标签、更正或来源授权有变 | 保存问题 ID、影响的场/时点/报告、根因、修复和回归夹具。赛果新旧版本都可查；按当前裁决撤销旧评分、重算训练和有效报表。历史已封存预测逐字节可取；历史原始报告另可按当时截止查询。 |
| 发布前重放 | 重复跑同一输入两次，赛程、配对分母、整数标签、状态与摘要完全一致。浮点容差和模拟种子先冻结。N4 关闭时与 N3 同输入同种子概率一致。每类关键时序至少有 1 个阳性和 1 个阴性夹具。 |
| 真实资格与覆盖 | 至少连续 14 个比赛日做只读影子运行，列全量应收/已收分母及来源新鲜度。不足日数或 0 笔可兑付时标为尚待现场验收。14 日只验证运行健康，前向研究按登记终点揭盲。 |
| 本地 Codex 修改与回滚 | 新版只在隔离副本修源、生成解释和回归测试，使用历史已揭盲部分验证，再比较新旧版的训练视图、封存与分母。加入有权源、修订旧规则或恢复退役源均须保留来源版本及生效时刻。独立复审通过方可升级，NBA 发布与回退均须通过原足球测试与旧库读取检查。 |
