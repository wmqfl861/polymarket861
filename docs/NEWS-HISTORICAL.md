2025/26 英超前 3 个官方轮次共 30 场。在相同的开球前 60 分钟，球队基线和加入合格新闻的候选均为 **73.640724 分**。两种新闻来源口径各有 30 对预测，均有 **0 场**发生概率变化。这批材料不足以判断新闻能否提高预测质量，也无法估计有效消息的平均增益。[逐场预测、四项评分及样本分母](../reports/news-history-0.4.0.json)

## 样本与时钟

样本按赛季、官方轮次和时点选取，所有无新闻、未识别球员、状态不明的比赛均留在分母。球队文章使用此前 7 天且晚于本队上一场该项联赛开球的时间段。球员文章使用同样的上一场限制，上限为 14 天。固定球衣号是补充历史采样的选择规则，未据此推测球员位置。此层与部署后日常信息源的覆盖单列。

采集器只查截止时间之前已经存在的版本。每个候选句都向前逐版查到实际引入它的修订，再检查直接上一个版本中是否确无该句。回顾性文章须有同期日期。补充的球员文章允许用同一赛季段落中附带引用的媒体发布日期判断时间范围，来源仍标为英文维基百科。访问日期不具备这一资格。公开材料记录了每个入选句、日期依据、历史名单和原件指纹。页面正文、引文正文以及未用于抽取的整队名单保留在采集端的原件缓存。[固定样本输入与修订索引](../reports/research/news-wiki-2025-26-rounds-01-03.json.gz)

原件实收于 **2026 年 11 月 25 日**，有本机真实赛前新闻收件的配对为 **0/30**。历史研究以截止前可证的公共修订作回看。足球训练使用固定版本的 OpenFootball 数据，沿用终场赛果在开球后 24 小时可得的研究假设和最终档案开球时刻。两个模型在同一训练集、同一截止点生成概率，然后才按终场比分计算四项适当评分。真正的前向样本来自部署后赛前封存的预测，由新闻轮报统计。[赛季模型治理](./model-release-governance.md)

## 复算

在仓库根目录启用项目的 Python 环境。首次获取 2022/23 至 2025/26 的四个原始赛季文件，后续比较可以离线进行。

```sh
pm861 football fetch .pm861-news-history --from-season 2022-23 --to-season 2025-26
python scripts/reproduce_news_history.py .pm861-news-history --output news-history-rerun.json
```

从服务方重新核对维基百科材料时使用独立的本机缓存。默认两路请求。缓存保存原始 HTTP 字节、请求选择条件、实际收件时刻、页面修订和哈希。新的采集时间将产生新的研究输入摘要。

```sh
python scripts/reproduce_news_history.py .pm861-news-history --capture .pm861-wiki-receipts --output reacquired.json
python scripts/reproduce_news_history.py .pm861-news-history --capture .pm861-wiki-receipts --offline-cache --output checked-offline.json
```
