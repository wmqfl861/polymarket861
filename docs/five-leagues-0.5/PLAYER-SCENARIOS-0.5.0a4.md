# 四国球员伤停情景与免费数据

西甲、德甲、意甲和法甲的研究预测把赛前可核实的球员缺阵另算一组概率。正式基线 B1 和现有新闻配对保持原口径。每次更新可以在封存的 `player_scenario.applied` 与 `excluded` 内查到球员身份、来源、系数或排除原因。此功能尚无线上预测改善结论。[修复对照](../../reports/five-leagues-0.5.0a4/player-scenarios.json)

## 球员记录格式

在与四国调度器相同的研究 `--data-dir` 中使用 `source register <manifest.json>` 登记免费来源实际获准的字段、获取方法及预测用途，再用 `evidence import <facts.json>` 写入观测。本地或对方拥有的实地观察可按实际权利登记。来源名、登记时间、原始出处和字段许可必须对应真实证据。

所有记录共用 `fixture_id`、`team`、`field`、`subject`、`source_id`、`method`、`locator`、`published_at` 和 `received_at`。每条记录的 `value` 均带 `competition`（`lal/bun/sea/fl1`）、`season` 和含时区的 `kickoff`。开球改期后旧记录保留在原时点。以下是各类记录实际需要的附加字段。

| 字段 | 输入 | 处理 |
| --- | --- | --- |
| `injury`、`availability`、`suspension` | `subject` 为球员全名，`availability` 为 `out`，`certainty` 为 `reported` 或 `confirmed`。伤病可附有依据且不晚于发布的 `injury_started_at`。 | 公布及本机观测在截止前，报告有效期 6 小时，与独立名单唯一匹配。明确回归、互相矛盾、已公布首发或替补中出现、名单姓名存在歧义，或适用其他赛事的停赛时，屏蔽相应缺阵效果。传闻不会直接改变情景。 |
| `lineup` | `confirmed: true` 和 11 个唯一首发全名。可附 `bench`，只记录来源明确列入的替补。 | 本场已确认首发和已列名替补可排除相同球员的缺阵。以前比赛的首发必须在当时开球前已本机收件，且比赛已在相同联赛和赛季终场。未列名球员的首发次数视为未知。 |
| `minutes` | 整队一期，`scope: domestic_season_to_date`、`as_of`、`completed_fixture_ids`、`players`。每名成员含 `name`、`position`（GK/DF/MF/FW）、非负整数 `starts` 和 `minutes`，可含 `appearances` 和稳定 `player_id`。 | 只接受最近 7 天同期观察的同队、同赛季联赛数据，至少 3 场。比赛 ID 须与当时已收终场的本队场次逐一相符；球队首发、门将首发和分钟总额按英超既有规则对账。分母最多为该赛季登记轮数，当前德甲和法甲为 34，西甲和意甲为 38。 |

同一断言更正时递增原记录的 `revision`，或以 `state: withdrawn` 撤回。来源授权、隔离及修订沿用现有证据系统的时点查询。对同一球队、同赛季同一统计时点互相矛盾的出场资料，系统回退到已确认的历史首发或中性估计。

## 系数和解释

出场重要性与英超沿用同一组常数。有整队资料时，取「出场分钟 ÷ 球队已赛分钟」和「首发场次 ÷ 球队已赛场次」的平均值，再将结果线性映射到 0.25–1.00。没有合格整队资料时，查询最近最多 8 场已终场比赛的已确认首发与明确列名替补，至少覆盖 3 场且达到窗口场次的 75%，按确认首发份额求系数。其余外场球员固定取 0.55。门将只在可核实首发数严格超过整个已赛窗口的一半时生效，缺名单场次也计入分母；位置未知且无法从合格出场目录补足时排除。

单人对数进球率移动量由位置效应、缺阵确信程度、出场重要性和伤停持续时间相乘。持续时间复用 B1 训练样本，计算在已知受伤时间之前各场权重占比。原始受伤时间缺失时以同一断言本轮缺阵的首次本机观测为依据。连续重申延用该时点，明确恢复或撤回后再发生缺阵时重新计时。双方进球率各自受已有上限保护。此规则估计赛前可用性带来的敏感度；收盘价检验和正式模型晋级仍需独立研究。
