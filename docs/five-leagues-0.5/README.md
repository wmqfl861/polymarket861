## 本次调查改变了哪些设计

1. **一套比分引擎，五套联赛校准。** 2021/22–2025/26 固定档案的 8,908 个常规赛席位中有 8,887 个可读比分；排除三个已知行政判罚后，8,884 个可用于初步描述。德甲全场大 2.5 的比例为 61.06%，西甲为 47.35%；意甲平局为 27.35%，英超为 23.89%。同一组英超进球基准会影响胜平负，也会同时影响三种大小球。保留同一个联合比分分布与四类概率换算，优先训练各联赛自己的基线、主场效应和攻防强度。跨联赛共享参数列为待比较的候选。[原始盘点及排除清单](evidence/history.json) · [比较设计](MODEL-AND-VALIDATION.md)
2. **赛果回测与可成交盘口回测需要各算一遍覆盖率。** 在 2025/26 五大联赛 1,752 个常规赛席位中，严格按赛事、主客和日期配对，找到完整胜平负目录 1,730 场、全场大小 1,337 场，主、客队大小各 0 场。2026-11-27 至 12-01（UTC，右端不含）的 48 个目录主赛事则全部找到四类盘口。各联赛取一场抽查，60 枚结果代币均收到有买卖两边的报价和数量。查得挂牌或某一刻有报价，都不足以重建过去某个截止点的可成交成本。新版本须从开始值守起归档未来的真实双时点盘口、费用和结算。[查询、对应场次与限制](POLYMARKET.md)
3. **基础比分可以覆盖五国，带收件时间的伤停和首发需要逐国建立。** 德甲的 OpenLigaDB 有五季 1,530 个历史终场条目；本次没有找到在其目录中覆盖当前西、意、法顶级联赛的同等来源。西、意各自缺失的 2024/25 末轮十个比分有可定位的维基修订可补，取证日期和上游独立性必须随结果保留。Touchline Wire 的当前伤停与预计名单产品说明以英超为范围。欧洲赛事记录、空伤病表、赛后名册都不能替代国内联赛赛前已确认的队员状态。[各国调查](LEAGUES-AND-SOURCES.md) · [Touchline Wire](https://touchlinewire.com/docs)
4. **轮次、时间和赛事规则必须按赛季登记。** 2026/27 是 96 支球队、1,752 场常规赛。英、西、意每季各 380 场；德、法各 306 场。法甲 2022/23 仍有 380 场。意甲的名次决胜、德法升降级附加赛、延期续赛和行政判罚都有真实反例。训练记录保留已踢的常规时间事实，积分榜使用适用裁定，账本使用逐合同兑付。轮次采用组织方归属，实际时间决定信息能否进入模型。[各国赛规与实例](LEAGUES-AND-SOURCES.md) · [法甲改制决议](https://www.lfp.fr/article/l-assemblee-generale-adopte-a-97-28-le-passage-a-18-clubs)

## 一场比赛怎样贯穿系统

| 环节 | 核心数据与决定 | 输出及边界 |
|---|---|---|
| 身份与赛历 | 以赛事、赛季、阶段和稳定赛事内比赛 ID 定位。开球排期有修订号，球队主客和有向配对作校验。球队、球员用稳定实体 ID，加上来源别名、转会效期、赛季成员和比赛地点。 | 同队参加联赛及欧战可共享球员身份，各有比赛与纪律范围。改期产生新排期版本；中断恢复关联同一场首次开球。 |
| 连续采集 | 赛程、赛果、名单、伤停、纪律、俱乐部新闻、天气预报及 Polymarket 目录都保留来源协议、生效时间、发布/修订、本机收件、内容指纹与上游依赖。 | 输出“截至该时可用”的可重放事实和冲突。许可不足的站点仅保留允许的引用或人工核对记录。冷热频率依服务条款与实测延迟配置。 |
| 生成与更新 | 开球前 24 小时封存预判和行情，60 分钟封存主预测及主账户唯一一次固定买入意图。已授权的球队新闻核实后可提前或在两窗之间触发增量预测；同一事实的译稿或重复采样不重复触发。 | 每次记录采用的模型和输入、主客进球分布、四项概率及变化原因。赛中及赛后新闻只走事实修订或评估。 |
| 市场与持仓 | 连接到同一场、相同方向和结算范围的合约与 token，读取买方付出的卖盘价量、费用、滑点和延迟，核对决策与执行的两次原始盘口。 | 每一策略单独一个跨五联赛的模拟账户；成交后分两路记录。开球前合格收盘报价用于 CLV；逐合约持有至交易所最终兑付，再计算净回报、费用与回撤。 |
| 逐轮测评与优化 | 正常赛果到齐后按官方轮次评分。有延期先发阶段报告，补齐重发有版本的轮报。候选按赛前冻结的共同比赛集与正式配方比较。 | 中文看板按联赛、赛季、轮次、玩法、时点切换。留存错误输入、判定依据、受影响的预测/轮报和修复后复跑。本地 Codex 可提交模型、解析器和新来源提案。 |

公共数据层按“赛事 × 字段 × 来源 × 使用目的”记录资格。举例说，一项来源可用于校核西甲完赛比分，同时在赛前首发、可用于公开再分发或严格回放三列中保持缺证。调度与资格也逐联赛隔离，法甲某轮延期或意甲某个盘口模板有变化时，其他赛事继续封存和评分。用户在同一个看板看到概率、球员/新闻依据、当前模拟机会和能力缺口，不需要来自五个项目的报表。

## 发布时如何判断做到了哪一步

| 可报告的能力 | 必须附带的证据 | 资料不足时的显示 |
|---|---|---|
| 历史赛果预测 | 按联赛的滚动比分回测、所有应评赛事、四分项、归档假设与严格回放分列；重跑可复现 | 展示最后可信的联赛基线、缺的赛季或标签和训练数据时效。 |
| 赛前固定窗预测 | 比赛和时区已核实、赛前实际收件、可用训练样本、双窗封存、评分与漏报分母 | 提前技术观测单列；越过截止时间只记漏窗。 |
| 球员／新闻增强 | 当季有效身份及事实资格、双队覆盖、原文依据和时间、B1/B3 同场同刻消融，达到逐联赛历史及前向门槛 | 仍可展示来源和影子结果。正式增强指针保持已获批准的版本。 |
| Polymarket 纸面持仓 | 准确发现、条款与代币双向核对、赛前双份可执行簿、费用、钱包可用模拟资金、适用结算向量 | 可显示足球概率；列出未挂牌、条款待审、缺盘口、缺名单或未兑付。合格成交为零时收益率和 CLV 留空。 |
| 全面可用 | 五国分别交付上述矩阵及逐轮报告，每个绿灯能点回原始凭据；源失效和错判的演练能恢复，英超回归通过 | 按联赛和玩法标出待观察项、取得下一份证据的办法与负责人。全项目指标保留每个分母和最低表现联赛。 |

## 提请 Claude 重点审阅

- 查核常规赛排除和赛季分母，尤其是法甲改制、意甲决胜赛、德法升降级附加赛、改期重复市场及已开球后续赛。检查真实比赛 ID、旧赔率合约和结算记录能否保持各自原貌。
- 逐一检视来源授权、是否允许自动采集、建模与留存，转载依赖及首次可知时间。尤其检查四个新增联赛是否有任何环节把“没有伤病条目”当成“全员健康”。
- 用附件重算五季历史分母、盘口覆盖及各联赛进球和赛果的频率差异；检查联合比分的四种概率、升班马处理、按联赛的盲评与候选比较能否发现负迁移。
- 检查单队大小的历史价格缺口、真实开球证明、异常兑付、共享资金和成本估算，明确每个结论能用哪一层证据支持。
- 检查工单顺序与验收门槛。请为每个发现给出对应文件章节、触发样例、受影响的联赛或玩法、建议改变的决策以及可复验的结果。

本次提案选择先让英超回归和德甲验证共用引擎，同时开展西、意、法的同范围数据与规则验证。五个联赛共用同一份交付清单，数据较慢的字段允许逐项积累实际观测。[并行工作包与预计周期](DEVELOPMENT-PLAN.md)
