# 五大联赛比分模型与验证计划

**0.5 拟共用一套比分建模代码，在五个联赛分别训练、校准、评分与决定是否启用。** 第一个可检验的版本是各联赛自己的基础模型。跨联赛共享参数、阵容情景和新闻各自登记为候选。每个候选都用同场对照检验，在当时可知的信息下能否改善赛前概率。

预测对象是常规联赛的赛前胜平负、全场大小球和主客两队各自的大小球，结果取常规90分钟含补时。赛前买入、持有至结算的模拟收益单独依实际 Polymarket 合约、执行价格、深度、费用和兑付计量。本轮完成历史数据盘点与设计，基线代码为 [0.4.2 对应提交](https://github.com/wmqfl861/polymarket861/tree/8125d579106dad51c694a97fdf6adf342e58adbb)。

## 比分模型怎样扩展

| 层次 | 当地方案 | 比较与采用条件 |
|---|---|---|
| B0 经验基线 | 每个联赛只使用截止前可得的本地比分构造经验联合分布，优先取可验证的过往完整赛季。预登记完整赛季及非常规终止处理，显式记录使用了哪些场次和回退原因。 | 为五国各自建立最低比较基线。新球队或数据不足可给B0概率并同时披露置信依据。 |
| B1 球队实力 | 沿用带时间衰减和正则化的Dixon–Coles模型，每个联赛分别估总体进球强度、主场优势、俱乐部攻防，以及0–0、0–1、1–0、1–1的低比分修正。当前初始比较采用最低40场、每日衰减0.002、岭惩罚8。 | 先逐国比较B1与B0，再评估局部调参、冷启动改进。截尾误差、概率和值与旧英超基线需可复算。Dixon–Coles原研究使用英格兰历史样本，其他联赛需要实测。[原论文](https://academic.oup.com/jrsssc/article-abstract/46/2/265/6990546) |
| B1 候选——校准与升班队 | 当前已有两项研究实现。一项用过去的滚动预测校准大2.5，再按比例调整相关比分格。另一项只在出现未见球队时尝试本联赛历史升班队先验。新计划按当地当年参赛名单、升班途径、曾否在顶级联赛出现区分。先验只用过去已结束且已收录的球队赛季。 | 同当地原B1逐场比较，另报首次出场、前五场、降级后立即回归、通过附加赛升班、可用二级数据与缺失的结果。有合法且稳定的二级来源时另登记适配强度的候选。既有英超两项五季研究的校正区间均含零。[既有候选实测](../football-candidate-experiments.md) |
| 跨联赛分层候选 | 可以部分共享收缩方差、季初进球率先验或衰减。仍保留联赛自己的总体进球率、主场优势、低分系数和联赛内中心化的球队效应。只靠互不交手的五套国内结果，无法识别球队间的跨国绝对实力。 | 与五个独立训练的本地B1同输入比较，增加逐国留出、后续赛季、低样本升班队和强弱两端的测试。汇总改善而个别国家退步时，该国维持已批准基线。分层模型的过度收缩在意甲研究中已有实例。[Baio与Blangiardo](https://discovery.ucl.ac.uk/id/eprint/16040/) |
| B2 阵容和场外情景 | 现版以同一B1比分矩阵为基础，把有证据的主客进球变化按情景概率混合。可候选加入已知首发、此前的上场分钟、休息、旅行、天气预报、教练更替和场地变更。 | 对每项或预登记的小组作剔除对照，同一事件只计一次。保留现有冲突和超限回退，更换情景概率或多事件依赖关系须重新验证。 |
| B3 新闻 | 现版从同B1含普通冷启动回退生成“有新闻/无新闻”配对，所用位置影响幅度为预设值，尚未经五个联赛拟合。按国别、语言、来源实证后才尝试估计当地幅度。 | B2和B3是不同配方。若将两者组合，应另登记B1、单分支、组合的对照和球员事件去重规则。新闻增益只能由同场、同刻、同输入的结果检验。 |

所有配方输出一张联合比分矩阵。胜平负由矩阵下三角、对角与上三角求和，全场大小看主客进球之和，单队大小分别看该队边际分布。默认测试0.5、1.5、2.5、3.5四条半球线，也测试其他受支持的半球线。所有格非负、总质量为1，提供遗漏尾部上界，胜平负和为1，大小互补，盘口升高时大球概率单调不增。校准应重标定矩阵并重新推导所有结果，避免各盘口分开调整造成矛盾。整数、四分之一盘和与规则不符的合约应分别识别其结算结构，初版按既有半球线支持范围登记市场覆盖。[当前模型与输出实现](../../src/polymarket861/football_model.py)

## 新闻、名单、伤停与场外输入

| 输入 | 赛前可以使用的条件 | 反例和验收 |
|---|---|---|
| 名单、位置、状态 | 保存人员ID、队伍与赛事、在队/转会起止、名字原文及当地别名。赛季/转会前后的名单、伤病名单、复出训练、是否入选、首发、替补逐项标来源与时间。球员状态可取赛前已知的过往首发、分钟、连续休息，归属到当时的球队。 | 重音、同姓、首字母、短名、转会、租借回归、不同性别或年龄组、国家队消息，及只写“可能复出”的采访。训练日后更新的名单不能回填成过去已知。 |
| 伤病、传闻与确认 | 本地AI输出球员、事件、肯定/否定、不确定性、目标比赛、发布者、原语引文定位、发布日期/修订/接收、有效期。分别登记传闻、报道、官方确认、撤回。关键身份或目标赛事不明可弃权。 | 同一通讯社被多语转载只能算一个上游。无新闻、只见传闻、报道确认、来源抓取失败分别记。按语言、来源与赛季对真实许可材料独立盲标，预登记样本量和门槛，报告精确率、召回率、错人、过度认作确认、弃权和覆盖。现有英语32篇俱乐部短段中四字段精确率68.75%、召回率35.48%，样本也无独立复标，其他语言从头建立基线。[既有真实英语评测](../NEWS-REPLAY-0.4.1.md) |
| 红黄牌与停赛 | 用赛前已发生且已获的纪律记录，保存赛事/轮次、直接红/两黄转红、累计黄牌、豁免/清零、处罚适用比赛、申诉和最终生效日期，绑定当时的联赛/足协规则版本。 | 国内杯赛处罚能否带进联赛、国家队红牌、临时撤销、延迟作出的追加处罚都需有适用依据。缺黄牌数据保留未知，只有规则和适用场次都明确才将球员列为确认缺阵。禁止用目标比赛自身红黄牌、当场xG或临场结果。 |
| 赛程与外部条件 | 计算最后一次真正出场至本场首次开球的休息时间、赛前可知的短期赛程密度、旅距、杯赛/欧战参与和中立场。天气只能用截止前发布的预报，教练更替、公开赛场处罚/空场和交通变更须可溯源。 | 缺杯赛记录时标出休息天数测量不全，不能当成充分休息。核赛季冬歇、双赛、国际赛归队、延期、短期共用场地与开球地变更。赛后实况不能代替预报或首发信息。 |

新闻研究先保存各国无新闻的对照，再测试“仅官方确认”“加入可信报道”“改变伤停持续时间或球员重要性权重”等有限候选。一次试验家族最多三个挑战者。双边均采到消息、真正发生概率变化的子集与全部赛程分别公开，并按比赛等权，避免一次比赛被多次新闻触发后重复入样。0.4.2英超30场历史重建中，按俱乐部正式正文入模改变0场，加入选定球员传记的敏感性检验改变1场，严格同期本机收件为0。0.5应从各联赛第一天保留及时收件，才能逐步回答新闻究竟改善哪些玩法。[0.4.2历史与限制](../CLAUDE-REVIEW-RESPONSE-0.4.2.md)

## 回测与前向试验的顺序

1. **锁定输入与目标。** 每个联赛登记赛季成员、阶段、官方轮次、比赛ID、来源与版本、资格分母、特征截止规则和评价指标。原始档案、已核实90分钟场上赛果、纪律部门认定的积分比分和 Polymarket 兑付各有自己的状态与版本。固定训练期和测试期后，缺档要显示原始分母、可用数与排除理由。西甲/意甲2024/25各十场普通完赛标签缺失不可当作赛事豁免。
2. **历史资料分轨。** `probability-research-24h`保留“最终档案开球、开球后24小时才见比分”的敏感性假设。`formal-strict`复建决策时已获的赛程版本、训练比分、新闻/阵容和实际收件，只录有证明的输入。能通过公开历史修订重建的消息另外报告。老新闻今天首次下载、现代预测模型见过比赛结果、赛后版名单等均不能冒充当时收件。对可用时点不明或无法证明模型训练时点的AI抽取仅作限定的重建分析。
3. **按时间内外层滚动。** 用最早若干完整季预热，首先保留既有可得前三赛季加本赛季已结束且结果已收到的球队训练规则。以2021/22–2024/25依次作外层验证季，逐场或逐轮按真实可用时点重训。内层只用更早赛季的滚动预测选择超参数，例如在预登记小网格中检验每日衰减0.001/0.002/0.004和岭惩罚4/8/16。校准先验、升班策略和缺失处理一并在内层固定。记录每折最新训练标签的接收时点、样本数、训练/评估指纹，并分别复查法甲缩编前后、疫情异常季、赛季首尾和球队升级。各国暖身季不齐时按实际历史量记录，禁用未来季补足。
4. **保留最后完整赛季作冻结方案的历史留出。** 五季中的2025/26单独报告，规则、超参数、缺失处理和首要比较应在读取该季逐场评分前冻结。这个版本的描述统计及英超过往研究已经看过这五季，因此末季留出只作冻结方案的历史复核。若因末季结果修改设计，另登记版本和新前向样本，不重复宣称同一留出是独立验证。
5. **五地独立预登记前向。** 按当地第一场相关截止前封存假设、历史/严格轨道、现用配方和候选、语料版本、两侧可见的同一证据、正式轮窗、得分端点与预算。T−24h和T−60m按当时已知排期封存，实际首次开球修正后须复核仍为赛前。T−60m为既有主决策点评分，T−24h单报，若声称两个时点同时显著则预先将两者纳入多重比较。轮内可以检查采集/错误，预登记的正式前向比较维持整窗揭晓规则。
6. **行动范围分别批准。** 每个联赛都能先产出基础概率和技术轮报。新模型和真实模拟交易资格分别按该联赛证据决定。全场大小、主队大小、客队大小、胜平负各按当地具体合约和方向/盘口线分别给出通过、证据不足或暂停原因。概率上可计算但当时没有同合约/深度的格子可继续评分，机会池和收益另保留真实缺口。

**选单优劣和收益结论各有指标。** 选单原协议的主要检验量是同一机会池、相同预算下，每预登记比赛预算的含费 CLV 改善，下界按已登记的两个阶段判断。报告收益时另计已兑付现金减去买入价款（未含费）及全部费用，净收益率以已兑付仓位的累计含费投入为分母，同时披露未兑付占款、回撤和双方成交覆盖。若主张净收益有优势，需要事先登记净收益或 ROI 及同预算对照，在独立期按比赛/轮次给出对应差值和区间；零投入的收益率留空。
