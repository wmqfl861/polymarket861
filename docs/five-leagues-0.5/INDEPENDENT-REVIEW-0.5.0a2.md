## 真实盘口与模拟证据

我从两个采集时刻的国内联赛归档按条件号提取 Gamma 原件，逐项复核规则、球队和两枚代币。每个归档中 2,168 个挂牌条件有 912 个通过研究玩法映射，德甲 216、法甲 216、西甲 240、意甲 240。其余 1,256 个条件留在未映射集合。最新实采的 76 份首个赛事回执均缺少 `live`、`ended`、`gameStatus`、`status`。最新常规样本有 48 次订单簿观测，较早的常规样本有 2,280 次。两个时刻的 912 个受支持条件全部启用费用，候选的审核费率登记表为空。

另把各国一份真实挂牌条件和费用字段送入产品的目录、值守、分批取簿和研究资金回放。为这项端到端试验控制时钟和 CLOB 回复。在两腿都按模拟时钟到达的条件下，保留真实费用仍 4/4 因缺收费资产及舍入依据而拒绝。仅在明确改成停费的合成正对照中，研究档 4/4 得到模拟买入，默认严格档 4/4 拒绝。两份真实常规采样中，受试未来固定时窗的实收样本为 0。用户实例上真实固定窗、部署、升级批准及任何收益均未核实。

新闻功效的 108 格、每格 2,000 次模拟已独立重算，结果 SHA-256 为 `709373f440c2071fb41a0aa82d4a3c5e42cab8498264968f58cf6e3c2a74a7d9`。在单一模式/时代、650 场、噪声 5 个百分点、真斜率 0.5 的条件下，主胜功效 8.45%，全场大 2.5 只有 3.15%。实证结论依赖本机登记后的未泄漏原件和合格价格。协议在 2028-07-01 00:00 UTC 揭晓。

## 校验记录

独立 3.12.14 全套耗时 375.667 秒，共 629 项，628 通过、1 跳过、0 失败。三项真实 Chromium 看板测试全部通过。该宿主阻止 Unix datagram，文件和抽象地址均无法创建，因此跳过的是 systemd 通知套接字的真实收件测试。本机实际测到了前台子进程、心跳、失联与重启后的新 run ID，目标主机 systemd 用户会话、journal 和 watchdog 状态应以该机原件为准。
