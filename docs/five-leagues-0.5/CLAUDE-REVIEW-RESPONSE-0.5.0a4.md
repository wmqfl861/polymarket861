## 模型和研究决定

这版改进采集、封存、纠错和评分，没有用收到的结果拟合逐人的能力曲线。分钟和首发贡献只用于伤停情景。五季基准回放不含足以检验这些新消息的逐时点首发和新闻。要评价准确率、收盘优势和净收益，需要实际赛前收件、赛果和相应成交条件。英超 v2 仍未登记；跨五联赛的合并研究需单独预登记。[下一阶段](IMPLEMENTATION-PLAN.md) · [英超新闻试验设计](NEWS-ENDPOINT-V2.md)

## 独立反例追加的修复

- 真实盘口目录缺失、已经登记的比赛身份发生冲突、球队名单下载失败时，四国调度会显示具体来源和重试信息。其他场仍独立核验。UTC 零点跨日探针在前后五分钟分别收到 23、20 次完整采样，两版相同。[跨日回放](../../reports/five-leagues-0.5.0a4/rolling-scope.json)
- 同一时刻的比分冲突进入撤回状态。改期按当时收到的赛程绑定旧比分，改到未来的比赛退出当前训练和评分；缓存保留新赛程后的第一份证据，即便比分与旧赛程相同。随机 180 组、1,080 次截止时点的增量与全量对照一致。
- 确认名单中已列为替补的球员会推翻相反的缺阵报告。常规门将过半首发的分母包含缺名单的场次。同一伤情的重复通告沿用首次可证实的起点。通用导入复核采集时和首次登记时的逐字段授权，识别使用别名转录的受限来源。
- 英超球队名单核对赛事索引和逐场报告中的阶段、比分、队别、首发身份与收件时间。赛程来回更正也必须收到新版赛程下的名单。原件只存指纹及许可允许的规范事实。核对已有英超封存时，预测任务和读取命令使用相同的身份、时间与摘要校验。
