## 采集与球员身份

为每个“联赛、赛季、球队、语言、字段、用途”保留一行来源记录，登记发布者、上游供稿、许可正文及生效日、允许的轮询频率、缓存和保留期、署名及再分发条件、最后一次成功与下一次核验。免费访问、能获得 API 密钥和能读 RSS 各只证明相应的访问能力。只有在费用为零、所需用途有依据且字段试采合格时，调度器才可启用。对许可仅允许引用或人工核查的站点，界面保留法定范围内的出处和人工决定，不将正文交给 AI 或放入公开证据包。

- **稳定身份。** 同时保存赛季中的球队归属、男子一队／青年／女队、国家队、球员稳定标识、来源原名、各语种别名、名字与姓氏顺序、变音字符、出处和生效区间。西语双姓、德语变音、法语连字符及意语同姓有歧义时返回候选与弃用理由。跨队转会保留公告、注册生效、外借起止、首次名单四种日期，同期国家队征召不能终止俱乐部合同。示例是西甲英文季页 20/20 存在，但皇马英语球员章节嵌入另一页面，回看须同时锁定嵌入页的当时修订。五名西甲球员的 Wikidata 样本中四人有多个无止期球队声明，另一人没有无止期声明。公开身份适合协助消歧；入队、报名和当场首发需要额外证据。[皇马固定修订](https://en.wikipedia.org/w/index.php?oldid=1387899597) · [西语季页例](https://es.wikipedia.org/w/index.php?oldid=176467768) · [Wikidata 许可](https://www.wikidata.org/wiki/Wikidata:Licensing)
- **场次和名单。** 稳定比赛 ID 连接两队、赛事、赛季、阶段和时间版本。名单分为注册、征召、预测首发、官方首发、替补、临场更换、最终出场。记录当时的发布权威、人数、完整性、是否含青年或外借回归球员。没有可靠赛前名单时报告缺证。赛后报告里的首发和分钟可以成为标签及下一场之前可知的历史特征。
- **来源原件。** 本地记录原始发布时间、来源修订时间、本机首次收到此版本、解析完成、授权范围及指纹；另存出赛/处罚的适用比赛与生效区间。出现过去时间只有日期、时区未知或模板嵌入变动时降低精度。Wikimedia 抽取保留语言、页面 ID、父子修订、依赖修订、原文贡献者和许可。新句可追溯首次引入版本；版权另有约定的第三方文字、图片和被引用站点须单审。2026-05-04 后 Wikinews 全部语种只读，不能纳入持续覆盖分母。[Wikimedia 条款](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use) · [Wikinews 公告](https://en.wikinews.org/wiki/MediaWiki:Sitenotice)
- **采集轮换。** 先按发布者限速和条件 GET 轮询，再按球队、下场开球与源实际延迟安排优先级。EPL 0.4.2 已有的单源检查、6 小时覆盖窗及分页完整性保留版本。新来源登记各自的更新时段、超过容许延迟的处理和耗尽配额的替代来源。任何标成健康的请求仍须校验真实赛事、球队、语言、身份和记录数。西甲参数返回带英超球队的 HTTP 200 和真正返回“本队检查完且无更新”应显示两种状态。

## 一条新闻如何改变赛前预测

1. **拆成有证据的事实。** 每条标注保留原语言、主体、目标赛事/对手、事件、极性、证据级别、可用性、语气和有效期，以及合规原件中可复查的位置。证据级别区分直接确认、二手报道、传闻、明确否认。可用性分确定缺席、存疑、可出场、未知。否认传闻不会自动证明相反事实。官方转发未经证实的传闻仍按其措辞处理。训练恢复、轻伤、队医许可、入选名单、首发分别记录。
2. **决定适用时间。** 单场确认到该场结束或更正时止；处罚按决定、起效、执行、撤销的时间和赛事范围；伤停的“还需两周”记区间与复查时间。没有明确期限的事实到预登记复核点后降为未知，最近一篇旧文不能被轮询当作新消息。间隔长的伤病只有可靠后续证据才更新。分钟负荷只取此前已可用的实际出场和休息间隔，区分含补时口径、替补、加时（可作负荷）、缺少分钟及上下场时间冲突。新签约球员样本不足沿用球队先验并标明不确定性。
3. **处理翻译、转载和分歧。** 保存上游发布者、文章 ID、引用链、原语言、译文链接和事实指纹。先按同球员、事件、对手与时间归组，再追至最初公告。通讯社稿在三家媒体转载、官宣被球员页引用、官网两种语言，都只贡献一次原始事实权重。独立报道有不同直接证据才算新增证据。撤回、身份错误或同源明确冲突时隔离受影响的字段，保存版本。明确的新决定/更正可结束旧版本。跨来源冲突未解时保留并列证据和弃用原因。
4. **新闻触发与两个固定窗。** 对尚未首次开赛的比赛，只有有效事实的新增、更改、过期、撤回或合格首发变化才排入增量预测。按比赛、时点、模型版本和有效事实摘要幂等处理，输出此前和本次的主客进球率及四类概率变化。证据未变化、重复译文不新增预测。先后封存 T−24 h 与 T−60 min，均依据该时确证的赛程和实际输入截止。截止前须完成收件、身份匹配及解析，并能重取对应版本。T−59 才到的首发不能进入 T−60，仍可形成赛前研究更新。无可靠比赛时钟、错过窗口、已首次开球、复赛或赛后复查分别标记。两窗各计一回，临时研究更新数量不改变该比赛在轮报中的权重。[现有封存与更新](../TEAM-NEWS.md)
5. **形成模型输入。** 在本地按原文抽取，保留分类器/可选本地模型版本与弃权原因；界面的中文解释由结构化事实生成。新闻内容是输入数据，内含指令或网址不能启动工具、添加来源、执行命令或更改模型。传闻默认进球率权重为零；确定缺席须具备合格实体、直接证据、时间和赛事作用域。已在结构化伤停或首发中反映同一人的缺席只扣一次。赛前已知且能独立验证的替代人选、预计分钟和该球员历史贡献才进入候选；未分配的时间或未知状态有显式缺失掩码。董事会传言、球迷评论和没有出处的球队士气评分只保留适用的研究备注。

场外候选包括换帅及首场任期、旅途与跨国归队、联赛/杯赛赛程拥挤、比赛地点/中立场、空场或部分看台限制、球场状况、天气预警和赛前预报。登记许可证、地点、首次可知时间、影响范围、持续期与替代解释。天气锁定预报发布批次、球场坐标、有效时段；赛后实况或重分析仅作诊断。球员个人生活及病历之外的私密推测不设特征。每组先做单独消融，观察其相对队伍实力、休息日与主场效应有没有增量。[DWD 公开预报目录](https://opendata.dwd.de/weather/local_forecasts/mos/MOSMIX_L/) · [限制客区实例](https://www.interno.gov.it/it/notizie/inter-napoli-limitazioni-alla-vendita-biglietti-match-5-settembre)

## 盲标、消融和晋级

**语言层验收提议。** 英、西、德、意、法分别建立冻结盲测集，每语至少 100 个去重的新闻事件簇，每簇保留一个主盲测样本。抽样跨球队、赛季段和发布者，正例、无关事件、空提取全部计入。原文和翻译、同队同场更新、上游转载不得跨训练、调参与盲测划分。双人独立原语言标注、第三人裁决，标签只依当时可见的证据。只取有许可的文本或独立编写的例句；实际授权样本与编写例句分别报告，正式语言验收的 100 个来自真实授权事件。加泰语、巴斯克语等新增语种单独达到同一协议再进入正式输入。

| 指标 | 分母与计算方法 | 拟定验收线 |
|---|---|---|
| 核心实体及其作用域 | 分别对球员、球队、比赛标注实体位置与规范 ID。错指同名球员、转会前后、男/女/二队均计错；三类 F1 取等权均值并报逐类计数。 | 每语实体 macro-F1 ≥0.80，每类至少 10 个金标实例。 |
| 证据级别 | 对确认、报道、传闻、否认按同一事实键比对，漏报、错报和无依据新增均计入；四类逐类 F1 后等权平均。否定范围另报准确率与错例。 | 每语证据级别 macro-F1 ≥0.80，每类至少 10 个金标实例。 |
| “确认缺阵” | 精确率 = 真确认缺阵／系统判为确认缺阵，同时列召回率、金标确认数、预测确认数和误报原句标识。每语金标确认缺阵 ≥40、系统预测确认缺阵 ≥40，另有 ≥30 个不同难例簇，覆盖条件/否定、复训、同名或转会、翻译转载、首发与征召混淆、更正或裁定。每类难例至少 5 个，可多标签。 | 每语确认缺阵精确率 ≥0.95。列 Wilson 双侧 95% 区间；40 个预测中 38 个正确即便达到点阈值，其下界约 0.835，须同时显示不确定性与误报。 |

每语另报混淆矩阵、弃权率、授权来源覆盖率、训练/盲测跨簇冲突数（须为零）、两名标注员原始一致率与分歧裁决。F1 提供以事件簇为单位的 95% 重采样区间与种子。缺少样本、盲测已用于调参、某类零分母时标为待验证；补充新事件重新冻结，不在同一盲测集反复选版本。前向自然分布另统计精确率和告警率，分层金标的命中率不能冒充实际新闻流命中率。

法语 *forfait* 与 *incertain*、德语 *gesperrt* 与 *fraglich*、意语 *squalificato* 与 *diffidato*、西语 *alta médica* 与 *convocado*、英语 *ruled out* 与 *back in training* 用于设计对照样本。每组要加入有否定、转述、不同对手或时限的语句，验收看整句中的人物、范围和证据。

**预测层验收提议。** 按联赛、窗口、玩法登记同时点同比赛的无新闻基线及有新闻候选。两臂使用相同训练切片、源时钟、比赛集合和正常终场，逐场保存四类概率、综合分及各分项、log loss、Brier、校准和覆盖。候选在同一注册比较中可区分名单/分钟、伤停与纪律、增量新闻、场外因素，各阶段遵守主计划的候选限额和多重比较。额外公布双队覆盖、单边覆盖、无消息、概率变化的场数，各自占原始分母，以及消息到窗的延迟和来源/球队偏差。只挑出现重大新闻的比赛不能代表全季增益。

现有英超口径分别登记主客两队实际被观测（`both_teams_observed`）和已达到研究准入（`both_teams_study_qualified`）。新联赛逐队记录名单、可用性及分钟证据的新鲜度、来源字段和拒绝理由，同一场同一窗两端均满足冻结协议才能计入正式双端分母。一队缺资料仍可保留基线和有标记的研究对照；如需验证非分钟替代字段，先登记新研究协议并进行平行验证。研究时点下的部分合格资料不自动取得正式资格。新闻与盘口关系沿用实际开球 `market_close` 和计划开球 `scheduled_market_close` 的独立报告，前者需要真实首哨及对应合格盘口。

语言通过只授予该版本相应事实的抽取资格。预测增益按联赛分别在历史和前向揭晓，同场按官方轮聚类。英语证据不能补贴其他语种，T−24 h 与 T−60 min 分开，技术重建、正式收件、纸面交易账本分别报告。全季按预登记规则要求所有官方轮次及至少 95% 配对，20 队常规赛 361/380、18 队 291/306。正式模型升级还需完整严格历史、合格前向对照及独立签署，并维持已登记的双端证据、评分、资格与账户约束。达不到条件时继续保持当前合格基线和有标记的影子新闻预测。[模型与统计算法](MODEL-AND-VALIDATION.md) · [现有模型治理](../model-release-governance.md)

## 每轮运营、错误根因和来源迭代

| 时间和责任 | 操作 | 验收证据 |
|---|---|---|
| 赛前持续值守，采集器 | 按来源轮换，监控请求成功、业务球队/赛事、分页和“收件至可预测”耗时；优先两个决策窗，地区来源限流退避。赛程更新记录原排期和接收时间，重新计算未来任务截止。 | 来源健康表同时展示距最后有效事实、核验时间、有效球队数、失败/空表含义、可用备用源；同一发布者重复成功不可掩盖别队饥饿。 |
| 每轮最后一批计划比赛结束，轮报程序 | 以官方联赛/赛季/轮号汇总，将已核实终场、待核、补赛/行政裁决、漏窗及已评分分别列出。对已批准配方及具名的探索性对照，列两窗四项成绩、校准、新闻增量、经人工复核的误报/漏报和按当时真实行情模拟的持仓费用和兑付。未挂牌或未成交时如实给分母。 | 一份可复算的带版本轮报，附应有/已封存/已配对/已评分场数和独立缺件原因。后轮可独立出报，无须等待前轮补赛。比分更正重算受影响的总分、各大小球和累计指标。 |
| 新证据到达，纠错程序 | 分清原数据错误、来源映射/别名错误、抽取错误、时钟错误、赛后裁定。保存旧原件、发现时刻、正确依据、隔离原因、影响的球员事实、比赛、预测、模型训练、轮报及账本 ID。可验证的撤回追加新版本；按当时可知视角保留原预测与原持仓。 | 纠正确认后重放受影响期间，输出原始当时视图、修正后重算视图、概率和评分差异、哪些持仓只能按交易所已定结果处置。公开轮报只追加版本和差异，不覆盖先前数据。加入最小复现场景、回归断言和同类联赛扫描。 |
| 每轮和异常触发，来源维护任务 | 每源复核真实更新、许可/免费层、上游血缘、队伍/字段覆盖、时效和更正率。发现新来源先提出申请，记录准确 URL、样本时间和字段用途。权限或字段语义变化先隔离相应功能，以已验证来源降级，保存历史批准并遵守保留/删除义务。 | 新来源走“发现 → 权利登记 → 只读试采 → 双轨比对 → 字段级准入”，如无权试采则停在许可登记。单字段切换至少两个完整轮次且 20 个适用且可独立核实的样本；18 队联赛两轮只有 18 场，必要时继续采。缺证继续影子。退役后未来调度停止，可用备份源承接并留回滚记录。[来源细则](LEAGUES-AND-SOURCES.md) |
| 每轮结报后，本地 Codex 和独立审核者 | 从聚合故障、数据变化、识别混淆、已批准配方或已揭晓的分项表现生成任务。可提来源增删/字段解释、采集与解析修复、去重或语言候选、特征和模型提案。分工作树/隔离数据库并行，锁定输入与代码摘要、运行预算和超时。来源发现任务只输出候选地址、用途及许可依据，不能自行把新域名写入联网清单或使用原件中的链接安装依赖。受限原文及密钥留在许可和隔离范围内，候选不直写生产。 | 同一证据离线可复算；样本期败例、英超回归、跨联赛污染测试、独立盲评与影子结果随提案提交。确定性修复按已授权治理切换；改变特征、权重、证据资格、资金或策略必须新协议或具名审批。守住单写者和幂等键，发布指针、来源配置和模型可退回已签版本。 |

正式预登记候选在揭晓前只公开应收/已收场次、输入资格、存证和流程健康。每轮可对已批准配方打分，也可发布预先明确为探索性且独立于该试验的数据。活动窗口内的候选得分、候选与基线的分差及间接可推导这些分差的明细，在整窗达到预定揭晓点后才提供给研究者、看板或本地 Codex。这样既能每轮纠正数据错误，也能保护这次前向检验的独立性。
