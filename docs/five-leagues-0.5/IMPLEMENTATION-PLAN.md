## 英超 0.4.2 复核的处理

S0-1 的目标机版本和签署状态交由该实例既有治理检查，新安装无需旧生产库即可开发。S1-1 与 P0-4 合并。S1-2 以 0.4.2 自己的十场封存重算规划报告，修正 760 场、斜率 0.5 的检出率。S1-3 与 P0-2 共用前瞻证据。S2-1/2 公开名单首发总量偏差与早一份合格目录的取舍，容差须防止跨赛事混入。S2-3 只用可验证的伤停日期。S2-4 为新增大小球斜率另登记多重校正家族。S2-5 并入 P2-1，S2-6 保留数值容差与精确的运行环境记录。开发、研究、正式批准分工独立。

## 0.5.0a3 部署后的取证

1. 在目标主机验证四国目录健康。每轮按应到窗口、订单簿实收、明确赛前与仅排期分别统计，漏窗按直接错误归因。
2. 对有双时点及兑付原件的场次，分别复算正式费用与研究估计费用，报告实际绑定的份额、净额和仍未兑付笔数。
3. 用本机封存做英超新闻预检，核实逐源留存条件、可绑定事实及期内固定的新闻策略，再决定是否前瞻登记。继续观察非英超的逐国来源授权和盲评覆盖。
4. 用各玩法独立前向样本复查历史评分，单列全场大 2.5 与主客单队进球。正式资格由逐项收件与本地治理决定。[安装与验收](DEPLOY-0.5.0a3.md)
