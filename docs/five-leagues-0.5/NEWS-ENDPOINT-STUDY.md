# 英超新闻调整与全场大 2.5 的前瞻研究

本研究回答两个问题。赛前新闻将主胜概率上调或下调时，合格临近开球的 Polymarket 概率平均跟随多少？相同的关系能否在全场大 2.5 球上观察到？两个端点允许给出不同方向的答案。登记版本为 `epl-news-home-and-full-over-v1`，限男子英超常规赛。每个部署选择一个模式，一次登记覆盖两个决策窗。

```sh
pm861 leagues news-endpoints plan
pm861 --data-dir /srv/pm861 leagues news-endpoints register --mode technical
pm861 --data-dir /srv/pm861 leagues news-endpoints report
```

默认立即登记。如需预约，给 `register` 加 `--starts-at` 和一个带时区的未来时刻。首次登记选择的开始时间、`technical` 或 `formal` 模式、协议摘要、本机登记时间一起生成登记摘要。相同设置可重复运行。不同设置会报错。选择日期要求早于 2028-07-01 00:00 UTC。安装后可先看 `report`，空库会显示 `not_registered` 和每一格实际的 0。

## 封存资格

登记时在同一 SQLite 写事务内安装捕获触发器。运行原有英超预测作业时，符合条件的新主封存和附带的研究绑定一同提交和回滚。绑定保存原封存摘要、登记摘要、本机插入时刻和概率实现版本。数据库里原来已有的预测没有这项绑定。技术回放、影子预测、其他联赛、其他模式、过期决策窗、开始时点之前已冻结输入的比赛均进不了新样本。

按数据库捕获顺序选择首个带原生合法格式研究声明的概率实现版本。后续不同版本专列原因。报告按原预测的输入截止时间重新打开新闻、名单及两队实际采集依据，并逐字段对照封存内的事实、来源和覆盖。若原件丢失或别的来源给出相同结论，这对样本会进入缺件清单。按每赛季、每场和每决策窗只取一个可核实主封存。其他场次仍进入已到时的本地排期分母。名单不全、赛前证据不合格、原件丢失、两个报价不属同一合约或实际第一声哨未核实，都留有缺件原因。

有资格的采集回执须能重开本机保留的上游响应，并用同一来源配置、入参和当时的游标重新解析。每一端的正向覆盖都要找到当时那次检查，即使正版 RSS 合法返回零篇文章也照此复核。已用球员另核对应的历史名单模板、每批身份响应、刊布修订、原报道和抽取记录。授权明确的免费来源在登记后可保留私有响应，当前自动覆盖登记为 CC0、CC BY 4.0 或 CC BY-SA 4.0 的正文数据源；标题转引许可和只保留规范化字段的来源继续按各自许可运行。缺少原件、采集权限或解析凭据的研究记录会列出 `missing_or_invalid_news_dependency_original`。运营查询仍能单独展示已经获准的事实或摘要。

每批采集先完成已认领球队的文章接收、去重、归档、球员识别和覆盖检查，再将原始响应的不可变副本交给研究留存。副本保存失败时，研究报告记录缺件，运营预测按已提交的事实计算。新新闻配方把来源选择、收件时钟、实际投递的文章、采集资格与名单提取纳入指纹。同一版 B1 可以产生多份不同新闻配方的预测。回放按每场当时封存的 B1 和新闻配方两个摘要分别核验。早期将两者合并签名的预测按当时的签名归入对应版本。

## 十项同时推断

| 每个决策窗的项目 | 横轴／比较 | 纵轴／裁定 |
|---|---|---|
| 主胜，真实首哨和排期开球各一项 | 有新闻主胜概率减 B1 主胜概率 | 同档已核实三向收盘的主胜概率减 B1 |
| 全场大 2.5，真实首哨和排期开球各一项 | 有新闻全场大 2.5 概率减 B1 同线概率 | 同档、大与小双方均已核实的合约收盘，取大球中间价减 B1 |
| 赛果评分护栏，一项 | 相同比赛上的有新闻综合分减 B1 综合分 | 双侧同时区间上界低于零，报告退化 |

实际首哨档要求独立的开球证明，排期档要求临近开球的原生交易所资料明确显示仍在赛前。盘口两端还要符合原有的合约、代币、规则、深度、价差、时钟及新鲜度要求。资料只符合其中一档就只计该档。0.5 斜率表示该端点收盘相对 B1 的变化，平均约相当于新闻调整幅度的一半。该数值本身不能证明预测准确性或可交易收益。

两个决策窗 T−24h、T−60min 各 5 项，一次 Bonferroni 校正共 10 项，家族置信度 95%。斜率回归过原点，按赛季与官方轮次聚类。未变化的预测仍计覆盖；只有大于 1e−12 的变化提供斜率信息。独立轮次不足、调整无变化或剩余方差无法估计时，报告缺少区间。赛果护栏只取已核实常规终场。
